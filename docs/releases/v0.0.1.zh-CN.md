# v0.0.1 — 基础编辑与运行

GameOfLife 首个版本，提供生命游戏的网格编辑与演化体验。

## 新增功能

- **经典生命游戏规则**：使用固定的 127 × 127 网格，按相邻八格的存活数量同步演化；网格边界有限，对侧不相连。
- **网格编辑与浏览**：编辑模式下点击单元格切换存活状态，按住拖动浏览网格，拖动范围限制在网格边界内。
- **步进与自动运行**：支持单步演化，或每隔 500 毫秒自动演化一次；暂停后保留当前图案并恢复编辑。
- **重置与清空**：重置可恢复上次编辑的状态；清空可移除所有活细胞。运行时执行这两项操作都会停止自动演化。
- **简约深色界面**：提供图标按钮、悬停提示和模式指示灯，青色表示编辑，琥珀色表示运行。
- **内置帮助页**：点击右上角的 `?` 查看演化规则与操作说明。

## 运行方式

需要 Java 25。使用 JAR 包时，执行：

```sh
java -jar GameOfLife-0.0.1.jar
```

也可以在 Windows 下从源码启动：

```powershell
.\gradlew.bat :lwjgl3:run
```
