# v0.0.1 — Basic Editing and Execution

The first release of GameOfLife, featuring grid editing and simulation for the Game of Life.

## New Features

- **Classic Game of Life rules**: A fixed 127 × 127 grid evolves synchronously based on the number of live cells among each cell's eight neighbors. The grid has finite boundaries; opposite edges are not connected.
- **Grid editing and navigation**: Click a cell in editing mode to toggle its state, or click and drag to pan across the grid. Panning is constrained to the grid boundaries.
- **Single steps and automatic simulation**: Advance one generation at a time or run automatically at 500 ms intervals. Pausing preserves the current pattern and returns to editing mode.
- **Reset and clear**: Reset restores the last edited state; clear removes all live cells. Either action also stops automatic simulation if it is running.
- **Minimal dark interface**: Icon buttons, hover hints, and a mode indicator keep the interface simple. Cyan indicates editing mode; amber indicates running mode.
- **Built-in help page**: Click the `?` in the upper-right corner to view the simulation rules and controls.

## How to Run

Java 25 is required. To launch the JAR, run:

```sh
java -jar GameOfLife-0.0.1.jar
```

You can also launch from source on Windows:

```powershell
.\gradlew.bat :lwjgl3:run
```
