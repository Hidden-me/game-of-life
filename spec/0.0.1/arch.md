# 0.0.1 版本架构

## 交互界面

交互界面是人机交互的接口。交互界面模块负责：
- 向上：向玩家显示画面，以及接收玩家输入。
- 向下：主动查询游戏数据用于绘制画面，以及根据玩家输入传递指令。

子模块如下。

### 视窗组件

用于支持视窗内显示元胞自动机状态，包括拖动操作。

### 输入处理

各界面元素接收到用户的有意义输入时，将控制流定向到这一子模块，集中处理用户输入，向会话模块传递指令。

### 画面渲染

组织各界面元素，包括视窗、步进按钮、运行按钮、暂停按钮、重置按钮、清空按钮、模式指示物。

通过会话查询快照，将快照中的元胞自动机状态传递给视窗组件进行绘制，并根据快照中的当前模式设置按钮的可用状态。

## 会话

会话是绝对可信的游戏状态唯一持有者，是唯一的业务逻辑接口。会话模块负责：
- 向上：接收查询与指令，提供结果。
- 向下：查询模型快照，或对模型执行指令。

本模块需要维护当前模式（运行、编辑），根据模式决定向下传递的查询、指令。

接口：
- 快照查询：返回一份快照，包含元胞自动机状态副本（对其改动不可传递到源状态）、当前模式。
- 步进指令：若在编辑模式，令元胞自动机做一次状态迁移。
- 运行指令：若在编辑模式，进入运行模式，在运行模式下每隔 500ms 自动步进一次。
- 暂停指令：若在运行模式，则退出运行模式。
- 重置指令：若在运行模式，则先退出运行模式。将元胞自动机状态重置到上次编辑的状态。
- 清空指令：若在运行模式，则先退出运行模式。将元胞自动机状态设置为空网格。

说明：
- 当前模式必定为运行模式、编辑模式中之一，退出一个模式意味着进入另一个模式，进入一个模式意味着退出另一个模式。
- 上述指令退出编辑模式时，以及编辑模式下变更元胞自动机的状态时，需要记录元胞自动机的当前状态为上次编辑的状态。

## 模型

模型模块负责记录游戏状态，即元胞自动机的状态，包括当前状态和上次编辑的状态。模型的初始元胞自动机当前状态、初始的上次编辑状态均为空网格。

模型向上提供一次状态迁移的接口。
